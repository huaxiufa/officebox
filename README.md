# OfficeBox

一站式开源综合办公工具箱。

## Vision

OfficeBox aims to bring common PDF, image, Office, OCR, media and AI utilities into one clean, self-hostable workspace.

## Roadmap

- [x] Project bootstrap
- [ ] Web dashboard
- [ ] PDF merge/split/compress
- [ ] Image conversion/compression
- [ ] Office conversion
- [ ] OCR
- [ ] Batch processing
- [ ] Docker deployment
- [ ] AI assistant
